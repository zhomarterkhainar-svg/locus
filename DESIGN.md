# Candid AI · дизайн-система «Каталожный ящик»

Фонд университета показан как карточный каталог: каждое фото принято на хранение как каталожная карточка с шифром, происхождением и штампом достоверности. Режим интерфейса: Operate. Цветовая стратегия: сдержанная (нейтрали + штемпель + карандаш).

## Цвета (`frontend/src/styles/tokens.css`)

| Токен | Значение | Роль |
|---|---|---|
| `--paper` | #e1e4e7 | холодная серая бумага, фон страниц |
| `--paper-deep` | #d4d9dd | дно ящика: панель фонда, подвал, скелетоны |
| `--card` | #f5f5f0 | светлый картон карточек, полей, диалога |
| `--guide` | #c9d0d5 | картон разделителей-вкладок |
| `--rule` / `--rule-soft` | #b3b9bf / #cfd4d8 | волосяные линии 1px |
| `--ink` / `--ink-2` / `--ink-3` | #172033 / #434d60 / #4f596b | сине-чёрные чернила текста, контраст AA на всех фонах |
| `--stamp` / `--stamp-deep` / `--stamp-wash` | #2340a8 / #1a3185 / #dfe4f3 | ультрамарин штемпеля: действия, выбор, «подтверждено», граница кампуса |
| `--pencil` / `--pencil-box` / `--pencil-wash` | #b8321c / #e2462b / #f3e1db | красный карандаш: рамки детектора, доказательства, изъятия |
| `--medium` | #574a0e | «вероятно», «есть основания», «мало», «старше 5 лет» |
| `--cold` / `--warm` | #4a67c9 / #c9432b | только данные: месяцы ниже и выше нуля на климатическом графике (пара проверена валидатором палитр dataviz) |

Запрещены градиенты, тени, стекло, неон, пастель, фиолетовый с чёрным. Глубина только линиями и сменой картона.

## Шрифты

- Golos Text 400/500/600 (кириллица, казахская кириллица, латиница) для всего интерфейса.
- PT Mono 400 только для полей карточки: шифр, даты, проценты, координаты, таймер, счётчики.
- Шкала: 11, 12, 13, 14, 16, 19, 23, 28, 34, 44 px. Заголовки 600, трекинг не меньше -0.025em.

## Форма

- Радиус 2px (вкладки 3px сверху). Линии 1px, акцентные разделители 1.5px чернилами.
- Отступы: 4, 8, 12, 16, 24, 32, 48, 64 px.
- Иконки: собственные SVG 16×16, штрих 1.5px, квадратные окончания. Никаких библиотек иконок и эмодзи.

## Компоненты

- **Каталожная карточка** (`CatalogCard`): превью 4:3, шифр раздела (`ОБЩ-004`), компактный штамп достоверности, заголовок в две строки, источник и дата `дд.мм.гггг`, отверстие под стержень внизу по центру. Наведение: рамка чернилами, без анимации. Доказательство факта: контур красным карандашом и рамки детектора поверх фото.
- **Штамп** (`Stamp`): рамка 1.5px цвета статуса. Сплошная ультрамарином для «подтверждено», пунктир `--medium` для «вероятно», точки карандашом для «не подтверждено».
- **Разделители** (`.guides`): одна строка вкладок из картона с верхними краями на трёх высотах, низ вровень с дном ящика, активная вкладка сливается с панелью. Малое число фото отмечается пунктирным подчёркиванием счётчика.
- **Прогресс сборки**: таймер PT Mono 34px, этапы с квадратными маркерами (пусто, наполовину, залито, ошибка), счётчики, свёрнутый список источников со статусами.
- **План кампуса**: SVG по данным OSM, граница заливкой `--stamp-wash`, объекты квадратами с буквой, фото точками карандаша, масштабная линейка.
- **Карточка фото** (`dialog`): фото с переключателем рамок детектора слева, поля карточки, таблица вклада сигналов и копии справа. На телефоне на весь экран.
- **Карта кампуса** (`CampusMap`): подложка CARTO light в проекции Web Mercator с приглушённой прозрачностью, поверх граница кампуса, объекты квадратами, пешие маршруты от общежитий пунктиром штемпеля, остановки полыми точками, фото точками карандаша (кликабельны). Атрибуция в подписи.
- **Город и дорога** (`CityPanel`): строки маршрутов с иконкой пешком/машина и временем полем PT Mono, плашка «зимней дороги», три счётчика инфраструктуры, климат: столбик от средней ночной до средней дневной температуры со скруглением 4px, риска среднего цветом картона, подсказка под графиком и скрытая таблица для чтения с экрана.
- **Фильтры и поиск по фото**: чипы-флажки из картона, выбранный чип окрашен `--stamp-wash`; поле поиска той же высоты, что маленькие кнопки.
- **Сравнение** (`/compare`): таблица из трёх колонок с липкой шапкой, разделы отбиты линией 1.5px чернилами, различающиеся строки отмечены словом «различается» полем штемпеля, в ячейке факт, штамп статуса и миниатюра-доказательство с шифром.
- **Скелетоны**: заливка `--paper-deep` с мягкой пульсацией, отключается при `prefers-reduced-motion`.

## Движение

Одно авторское движение: карточка «ложится в ящик» (сдвиг на 8px и проявление, 260ms, экспоненциальное замедление) при поступлении в фонд. Остальные изменения состояний мгновенные, без hover-анимаций.

## Текст

Русский язык, без длинного тире и конструкций «не X, а Y». Кнопки называют действие. Ошибки называют проблему и выход. «Не найдено» всегда сопровождается пояснением, что это не значит «нет».
