# Заранее собранный кэш карт OpenStreetMap

Публичные зеркала Overpass API в часы пик отвечают минутами. Чтобы профиль частых вузов сразу
показывал границу кампуса, здесь лежат сжатые ответы Overpass (только теги, которые читает сервис),
собранные скриптом `ml/seed_osm_cache.py` в GitHub Actions. Данные © участники OpenStreetMap, ODbL.

Сервис сначала смотрит свежий кэш сервера, затем этот каталог, затем идёт в Overpass. Фото здесь нет.
